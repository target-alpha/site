# Target Alpha Canada website

This is a dependency-free static website. Content, rendering, styling, and generated output are kept separate so routine updates do not require editing page layouts.

## Project tree

```text
.
├── index.html             # Browser shell; do not add page content here
├── app.js                 # Generated bundle for direct file:// use
├── public/                # Images, icons, and other static assets
├── scripts/               # Development, validation, bundling, and build tools
├── studio/                # Sanity Studio and CMS schemas
└── src/
    ├── content/           # Names, bios, images, events, links, and page metadata
    ├── components/        # Shared HTML components
    ├── pages/             # Page composition
    ├── styles/            # Site-wide CSS
    └── main.js            # Router and browser interactions
```

`dist/` is generated by the build and is intentionally not committed. Never edit `dist/` or `app.js` directly. Editors use Sanity after it is configured; repository content remains the fallback.

The generated `app.js` bundle also lets the root `index.html` run when it is opened directly from Finder. Route navigation automatically switches to hash-based URLs in that mode.

## Run locally

```bash
npm run dev
```

Open `http://localhost:4173`.

## Validate and build

```bash
npm run check
npm run build
```

The production site is generated in `dist/`. Every preserved Target Alpha route receives its own `index.html`, and the build also creates `sitemap.xml`, `robots.txt`, and `404.html`.

Pushing source changes to `main` runs the same validation and build automatically before GitHub Pages is updated.
